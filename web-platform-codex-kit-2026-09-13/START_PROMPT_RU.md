# Первый запрос к Codex

```text
$web-platform-release
Работаем с этой web-игрой. Сначала только прочитай проект и инструкции AGENTS.md.
Определи движок и точную версию, существующие SDK, сохранения, сборку и состояние MVP.
Ничего не меняй и не устанавливай до согласованного плана. Не переписывай архитектуру,
глобальные скрипты, баланс, сцены, сохранения, зависимости или систему сборки.
Если MVP не готов, покажи минимальные недостающие пункты и предложи отдельный план.
Когда MVP готов, спроси: «Под какую платформу готовим первый SDK-билд?»
Не выбирай площадку сам. Уже известные ответы повторно не спрашивай.
Затем уточни только недостающее: формат приложения, устройства, монетизацию,
сохранения и лидерборд, существующий интегратор и доступ к кабинету/выплатам.
Перед кодом предложи список конкретных новых/изменяемых файлов, команды и тесты.
После моего разрешения создай документы выбранной площадки и делай небольшие изменения.
Публикация, договоры, платные сервисы и глобальные изменения — только после отдельного разрешения.
```

## После проверки MVP
```text
$web-platform-release
MVP проверен. Для первого билда выбираю [площадка], [точный формат приложения].
Проверь PLATFORM_PROFILE и APPROVAL_LOG, не повторяй решённые вопросы.
Сначала обнови официальные требования и покажи минимальный план интеграции.
```

## Перенос на вторую площадку
```text
$web-platform-release
Нужно добавить [вторая площадка], не ломая работающую версию [первая площадка].
Проверь договорные ограничения и DISTRIBUTION_MATRIX. Не подключай второй SDK
поверх первого. Покажи отдельный профиль сборки и точный список изменений.
```

# Концепты для solo web-разработчика
Дата проверки референсов и правил: **13 сентября 2026**.

## Как пользоваться
Это **5 разных игр, предложенных в 14 позициях для 7 направлений**, а не план делать 14 проектов. Повторы специально показывают кросс-платформенность.
Концепты — авторские гипотезы, не прогноз гарантированной выручки. «Уютное фэнтези», «милые существа», «еда» и «дружелюбная sci-fi» здесь — понятные визуальные направления, а не доказанный рейтинг сеттингов каждой площадки. Ссылки подтверждают существование референсов механики, не их прибыль.
Некоторые референсы открываются на другом портале: это отмечено намеренно, особенно для VK/ОК. Не утверждается, что каждая из перечисленных игр присутствует на всех рекомендуемых платформах.

## Общая линейка

### A. Склад дирижаблей
**Жанр:** sorting/triple match. **Сеттинг:** уютный воздушный порт с почтовыми посылками, компасами, механическими птицами и дорожными наборами; не продуктовый супермаркет.
**Core:** сдвигать предметы по полкам → собирать тройки одинаковых → закрывать заказ отлетающего дирижабля → получать оплату → открывать новую полку/декорацию. Основное действие — одна понятная операция drag-and-drop.
**Отличие:** на смену приходит заказ с конкретными нужными тройками; игрок выбирает, какую полку освобождать первой. Только одно дополнительное правило за раз, без сложной логистики и физики коробок.
**MVP-граница:** один экран, 12–18 типов предметов, 20–30 проверенных раскладок из нескольких шаблонов, 3 визуальных улучшения. Решаемость проверять; не полагаться на произвольное перемешивание. Без прогулки по складу, сотрудников и симуляции транспорта.
**Мета:** три маршрута и декоративное обновление порта; не бесконечное дерево систем.
**Монетизация-гипотеза:** rewarded на подсказку/undo/дополнительное свободное место на текущий уровень; обычное прохождение возможно без рекламы. Interstitial между завершёнными партиями по правилам SDK. IAP не нужен для первого релиза.
**Референсы:** [Разложи по полочкам](https://yandex.ru/games/app/razlozhi-po-polochkam-master-sortirovki-327098) — читаемость полок, тройки, снятие предметов; [АСМР Сортировка](https://yandex.ru/games/app/asmr-sortirovka-359915) — тактильность перемещений и обратная связь.
**Смотреть:** первый ввод, читаемость свободного слота, размер предметов на телефоне, причины тупика и рестарта. Не копировать оформление/уровни.
**Производственный риск:** низкий относительно остальных концептов; главный риск — однообразие и баланс раскладок.
**Технология:** Phaser/HTML5; готовую Unity-версию не переписывать только ради смены движка.

### B. Заповедник карманных духов
**Жанр:** merge + idle-коллекция. **Сеттинг:** маленькие лесные/кристальные духи и их уютные убежища; не кибергонки и не обычная ферма.
**Core:** получить капсулу → объединить две одинаковые → поставить улучшенную капсулу в инкубатор → поселить духа в домик → собирать ресурс для новых объединений. Все цепочки предсказуемые, без платного случайного результата.
**Отличие:** на поле объединяются капсулы, а выставленные существа остаются в коллекции и визуально меняют уголок заповедника. Нет комбинаторного скрещивания всех видов.
**MVP-граница:** поле 4×4, один инкубатор, 4 места производства, 2 цепочки по 5 ступеней, 1 среда и 3 её декор-улучшения. Это оценка стартового объёма, не готовый баланс. Не добавлять PvP, обмен, питомцев-компаньонов и десятки островов.
**Мета:** открытие существ/домиков и небольшие задания «вывести духа нужной ступени». Оффлайн-доход ограничить согласованным cap; не строить возврат только на ожидании.
**Монетизация-гипотеза:** добровольное удвоение одного сбора/ускорение инкубации, без обязательного просмотра; оформление среды через IAP только там, где магазин разрешён и есть доступ. Для Poki — полностью без IAP.
**Референсы:** [Merge Cyber Racers](https://poki.com/en/g/merge-cyber-racers) — простое объединение и постановка объекта в доход; [Farm Merge Valley](https://www.crazygames.com/game/farm-merge-valley) — визуальные ступени и заказы. Второй референс значительно больше MVP: не копировать всю ферму и набор систем.
**Производственный риск:** умеренно низкий; основной труд — ясная экономика, отсутствие блокировки поля и потерянного прогресса.
**Технология:** Phaser/HTML5. Уже начатая egg/merge-игра может дать основу после отдельного аудита; это не разрешение на автоматическую переделку.

### C. Лунная мастерская
**Жанр:** компактный idle-production. **Сеттинг:** ремонтная мастерская на маленькой лунной станции с добрыми роботами; не добыча руды в шахте.
**Core:** разбор деталей → сборка корпуса → зарядка и отправка робота → доход → улучшение самого медленного из трёх участков. Активное действие — короткая настройка батареи, дающая временный бонус; не отдельная сложная мини-игра.
**Отличие:** игрок видит, где скапливается очередь, и выбирает узкое место; роботы пополняют визуальный каталог. Управление одним экраном, не персонажем в 3D.
**MVP-граница:** 3 фиксированных участка, 8 типов роботов как визуальные ступени, 3 вида upgrades, один интерьер. Без свободной расстановки конвейеров, транспорта, рабочих с pathfinding и рынка ресурсов.
**Мета:** восстановить станцию фиксированными улучшениями. Prestige не обязателен для первого теста, добавляется лишь при подтверждённой необходимости.
**Монетизация-гипотеза:** rewarded на временной производственный бонус и удвоение одного оффлайн-сбора, interstitial при завершении крупного заказа. Не останавливать производство исключительно ради принуждения к рекламе.
**Референсы:** [Idle Mining Empire](https://poki.com/en/g/idle-mining-empire) — узкие места, автоматизация и апгрейды; [Merge Mine: Idle Clicker](https://www.crazygames.com/game/merge-mine-idle-clicker) — быстрый отклик действия и заметное усиление.
**Производственный риск:** умеренный: отладить экономику/сейвы сложнее, чем внешний вид. Не обещать долгую игру только экспоненциальным ростом цен.
**Технология:** Phaser/HTML5 или уже работающий Unity Web проект.

### D. Музей невозможных находок
**Жанр:** hidden object + небольшое восстановление. **Сеттинг:** музей магических экспедиций с механической оранжереей, библиотекой путешественника и залом морских чудес; не бытовой интерьер.
**Core:** получить список предметов → найти их в диораме → завершить заказ → восстановить один экспонат → открыть следующий набор поиска.
**Отличие:** найденные предметы собирают конкретный экспонат, который меняет комнату. Никаких сюжетных ветвей и отдельного match-3 для строительства.
**MVP-граница:** 3 качественные сцены, около 20 различимых объектов в каждой, 12–18 заданий с управляемой перестановкой, 6 состояний восстановления. Сначала проверить читаемость предметов на реальном телефоне.
**Мета:** фиксированный путь реставрации; задания используют те же комнаты, но не должны требовать угадывания невидимых пикселей.
**Монетизация-гипотеза:** rewarded-подсказка/подсветка, interstitial после завершённого задания. Для первого теста без IAP.
**Референс:** [Hidden Objects](https://www.crazygames.com/game/hidden-objects) — список целей, поиск на сцене, подсказки и масштабирование. Смотреть читаемость и темп, а не копировать комнаты.
**Производственный риск:** выше A–C из-за арта и контента; второй проект, не самый дешёвый первый выбор.
**Технология:** Phaser/HTML5, слои иллюстраций и интерактивные области.

### E. Чайный вагончик духов
**Жанр:** короткие service/time-management смены. **Сеттинг:** чайное окно ночного поезда для милых духов-путешественников; не мороженое/пиццерия из референсов и не персонажи известного аниме.
**Core:** принять заказ → выбрать чайную основу → добавить одну начинку → подать → получить оценку/монеты → улучшить оборудование. Одновременно максимум 2–3 заказа.
**Отличие:** пассажиры запоминаются силуэтом и предпочтением, а у станции есть один простой модификатор смены. Сначала без модификаторов: проверить обычное обслуживание.
**MVP-граница:** один экран, 6 рецептов из общих компонентов, 4 типа гостей, 20 коротких смен, 3 улучшения. Без свободного движения, закупки ингредиентов, 3D готовки и сложного расписания поездов.
**Мета:** вагон получает фиксированные декоративные улучшения; следующая станция меняет фон и набор заказов, не добавляет новую игру.
**Монетизация-гипотеза:** rewarded на бонус чаевых после смены или одно дополнительное спокойное продолжение; стандартное продолжение рядом. Interstitial в разрешённой паузе. IAP не нужен.
**Референсы:** [Papa’s Freezeria](https://poki.com/en/g/papas-freezeria) — заказ, сборка, качество обслуживания; [Piece of Cake: Merge and Bake](https://www.crazygames.com/game/piece-of-cake-merge-and-bake) — уютное восстановление. Из второго брать только визуальную мету, НЕ добавлять merge как вторую основную механику.
**Производственный риск:** умеренный; основной риск — неудобное управление и чрезмерная сложность рецептов. Ограничивать число операций.
**Технология:** Phaser/HTML5.

## По два концепта на каждое направление

### 1. Яндекс Игры — A и B
**A «Склад дирижаблей».** Прямая понятная sorting-игра с рекламой, RU+EN, mouse/touch. Референс: [Разложи по полочкам](https://yandex.ru/games/app/razlozhi-po-polochkam-master-sortirovki-327098).
**B «Заповедник карманных духов».** Коллекция + merge; сначала rewarded, затем только при необходимости небольшой разрешённый магазин оформления. Референс: [Merge Cyber Racers](https://poki.com/en/g/merge-cyber-racers).
Маршрут: моя рекомендуемая первая техническая/коммерческая проверка из России, не обещание трафика. SDK и статус монетизации обязательны; договор проверяется отдельно.

### 2. VK — B и C
**B «Заповедник карманных духов».** Та же игра; проверить гостя/аккаунт, сохраняемую коллекцию и фактический mobile runtime. Не добавлять друзьям подарки и рейтинги «для галочки». Референсы: [Merge Cyber Racers](https://poki.com/en/g/merge-cyber-racers), [Farm Merge Valley](https://www.crazygames.com/game/farm-merge-valley).
**C «Лунная мастерская».** Возврат через продолжающуюся прогрессию и заметную автоматизацию; без социального сервера. Референс: [Idle Mining Empire](https://poki.com/en/g/idle-mining-empire).
Это механические референсы с других открытых порталов. Для выпуска сначала определить VK Mini Apps/legacy, рекламу и платежный договор.

### 3. Одноклассники — D и E
**D «Музей невозможных находок».** Спокойный поиск и фиксированная реставрация, крупные объекты/шрифт. Референс: [Hidden Objects](https://www.crazygames.com/game/hidden-objects).
**E «Чайный вагончик духов».** Тот же service loop, более спокойный старт и хорошо видимые ингредиенты. Референс: [Papa’s Freezeria](https://poki.com/en/g/papas-freezeria).
Не утверждается наличие этих референсов в ОК. Новые приложения официальный FAQ направляет через VK Mini Apps; старый FAPI нельзя выбирать автоматически.

### 4. CrazyGames — C и A
**C «Лунная мастерская».** Быстро показать три производственных этапа и первое осмысленное улучшение; EN, desktop+mobile при реальной поддержке. Референсы: [Idle Mining Empire](https://poki.com/en/g/idle-mining-empire), [Merge Mine](https://www.crazygames.com/game/merge-mine-idle-clicker).
**A «Склад дирижаблей».** Та же sorting-игра, минимум вступительного текста, быстрое начало и завершённые короткие уровни. Референс: [Разложи по полочкам](https://yandex.ru/games/app/razlozhi-po-polochkam-master-sortirovki-327098).
Basic Launch не монетизируется, Full — отдельный допуск. IAP и native leaderboard не считать доступными по умолчанию.

### 5. Poki — E и B
**E «Чайный вагончик духов».** Наиболее наглядная для теста версия: один экран, 2–3 операции приготовления, визуальное обучение, полноценный touch. Референс: [Papa’s Freezeria](https://poki.com/en/g/papas-freezeria).
**B «Заповедник карманных духов».** Merge/income без магазинов реальных денег и обязательных рекламных ожиданий; первый merge сразу показывает смысл игры. Референс: [Merge Cyber Racers](https://poki.com/en/g/merge-cyber-racers).
Здесь выше риск отбора площадкой, а не обязательно разработки. Ads-only. Перед любой кросс-публикацией проверить конкретную сделку: web-exclusive либо non-exclusive.

### 6. GameDistribution — A и D
**A «Склад дирижаблей».** Лёгкая понятная sorting-игра для встраивания, минимум зависимостей и текста. Референс: [АСМР Сортировка](https://yandex.ru/games/app/asmr-sortirovka-359915).
**D «Музей невозможных находок».** Законченные самостоятельные поисковые задания; понятные паузы для рекламы. Референс: [Hidden Objects](https://www.crazygames.com/game/hidden-objects).
Это сеть дистрибуции, не гарантированный приток аудитории. Проверить договор, SDK и исключить пересечение каналов с другим дистрибьютором.

### 7. Playgama — B и C
**B «Заповедник карманных духов».** Та же merge-коллекция, отдельный Bridge-профиль, без привязки core к native API одного портала. Референс: [Merge Cyber Racers](https://poki.com/en/g/merge-cyber-racers).
**C «Лунная мастерская».** Тот же компактный idle; функции покупок/рейтинга отключаются, если целевой хост их не даёт. Референс: [Idle Mining Empire](https://poki.com/en/g/idle-mining-empire).
Bridge v2 и дистрибуция — разные решения. Права, каналы, допуск монетизации и выплаты подтверждаются отдельно.

## Что делать первым
**Одна игра, не все пять.** Если существующая sorting/merge-игра уже работает, сначала аудит и доведение её до MVP. При равном старте A — наиболее компактный объём, B — больше прогрессии с умеренной сложностью.
Первый маршрут: Яндекс → проверка реального поведения/сейвов/дохода → одна следующая площадка (VK/ОК или CrazyGames) → один дистрибьютор с согласованными каналами.
Poki — отдельная попытка отбора, не единственный источник будущего дохода. При приоритете Poki сначала выяснить требования сделки к ранее опубликованной игре; не подписывать exclusivity после выдачи конфликтующих прав другим сетям.
D требует заметного арта; E — полировки управления; C — аккуратной экономики. «Низкий риск» здесь означает контролируемое производство, не гарантированный спрос.

## Чего не включать в первый релиз
PvP/онлайн-кооператив, обязательный backend, общий чат, пользовательский контент, торговлю между игроками, платные случайные награды, бесконечные ручные события, открытый 3D-мир, десятки мини-игр. Не копировать известные бренды и персонажей.

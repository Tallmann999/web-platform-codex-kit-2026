# Web Platform Release Kit — 13 сентября 2026

**Назначение:** переносимый Codex skill для Unity Web, Phaser и обычного HTML/JS.
Сначала аудит и проверка MVP; затем выбор площадки, согласованный план SDK, отдельная сборка и проверка.

Это набор рабочих инструкций, шаблонов и локальных проверок, **не универсальный установленный SDK** и не гарантия модерации, дохода или выплат.
Никакая игра в составе этого архива не публикуется. Реальный проект пользователя ещё не интегрировался и не тестировался.

## Начало работы
1. Скопируйте каталог `.agents/skills/web-platform-release` в корень Git-репозитория игры. Не внутрь Assets, src или готового Web-билда.
2. Откройте `AGENTS.append.md`. Добавьте его содержимое в существующий корневой `AGENTS.md`, не заменяя старые инструкции. Если AGENTS.md отсутствует, можно создать его с этим содержимым. При конфликте сначала согласуйте правила.
3. Откройте проект в Codex и отправьте текст из `START_PROMPT_RU.md`. Для явного вызова используйте `$web-platform-release`.
4. Не добавляйте весь набор в публикуемый ZIP игры: `.agents`, документация, тесты и секреты не являются игровыми ресурсами.

## Содержание
- `CONCEPTS_RU.md` — пять оригинальных концептов, по два предложения для семи направлений и матрица повторного использования.
- `.agents/skills/web-platform-release/SKILL.md` — основной порядок работы и точки остановки для согласования.
- `references/platforms/` внутри skill — Яндекс, VK, ОК, CrazyGames, Poki, GameDistribution, Playgama.
- `references/` — сборки, защита сохранений, реклама, покупки, лидерборды, ограничения договоров, движки и интеграторы.
- `assets/templates/` — документы, которые Codex заполнит для конкретной игры и площадки.
- `scripts/` — Python 3.10+, только стандартная библиотека. Два аудитора ничего не записывают; генератор документов по умолчанию показывает план, не пишет.
- `sources.json` — официальные источники, даты проверки и явно отмеченные пробелы.
- `TEST_REPORT.md` — фактически выполненные тесты утилит этого набора.

## Существенные оговорки
Правила прочитаны 2026-09-13 и требуют повторной проверки перед каждой подачей. Это авторские конспекты, а не полный архив чужой документации.
Часть страниц dev.vk.com недоступна автоматическому чтению: точный тип VK-приложения, реклама, платежи и маршрут ОК остаются обязательной ручной проверкой. FAQ ОК прямо направляет новые приложения в VK Mini Apps.
CrazyGames имеет ограничения доступа к IAP и лидербордам; Poki — отдельные договоры, включая web-эксклюзивность. Доступность банковских выплат из России нужно подтвердить для конкретной стороны договора.

Skill задаёт правила поведения, но не является технической песочницей. Git-ветка, проверка diff и ограничения разрешений Codex остаются необходимыми. Набор не меняет глобальные настройки Codex.

## До интеграции
Площадка курирует каталог, приём не гарантирован. Сначала проверить тип сделки: есть web-exclusive и non-exclusive. Нельзя считать ни «всегда эксклюзив», ни «всегда можно на другие сайты». Индивидуальный договор занести в DISTRIBUTION_MATRIX до портов.
Poki — рекламная модель: текущие правила не допускают IAP. В этой сборке убрать покупку валюты/отключения рекламы, а не оставить неработающий магазин.

## Технические особенности
Требуются desktop/mobile/tablet, соответствующее управление и пропорциональный canvas 16:9 на desktop; на mobile — полный экран выбранной ориентации. Не растягивать портретный UI просто в 16:9.
Внешние запросы по умолчанию блокируются: локализовать ассеты/библиотеки; исключения согласовать. Incognito/adblock должны оставаться играбельны. Только Poki ads; не добавлять внешний счетчик/аналитику без разрешения.
Lifecycle должен соответствовать странице требований: gameplayStart по первому игровому input; stop при прерывании; нельзя дублировать start/start и stop/stop. commercialBreak вызывается при возвращении из паузы в игру, а не при уходе из игры в меню. Не встраивать собственный таймер рекламной частоты.

## Rewarded
`rewardedBreak` требует проверить успешный результат. Стандартное продолжение доступно наряду с rewarded. Текущие правила UI: у rewarded явный значок видео, кнопка не зелёная; обычная кнопка не менее заметна и не меньше. Один просмотр — один бонус; no-fill/adblock не дают награду. Детали и актуальный список перед релизом сверить с требованиями.

## Данные/рейтинг
Accounts могут требовать включения менеджером, есть гостевой/отказной режим. AUDS — хранилище пользовательских данных, не универсальный API общего leaderboard. Не создавать обязательный внешний аккаунт/сервер ради рейтинга без отдельного согласования.

## Профиль и QA
Сделка и право кросс-публикации, SDK версия, public ID, поддерживаемые устройства, layout-профили, whitelist запросов, сохранение, ad placements. Тестировать настоящий Poki preview/Inspector, incognito, adblock, touch/tablet, resize, mute и отсутствие IAP UI. Подготовить необходимые статичную/анимированную обложки по актуальным требованиям.
Wire/PayPal в справке выплат не подтверждают работоспособность конкретного российского маршрута — требуется подтверждение поддержки.

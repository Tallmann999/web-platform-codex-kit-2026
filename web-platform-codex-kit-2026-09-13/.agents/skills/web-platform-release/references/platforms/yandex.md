## Минимум к публикации
SDK обязателен; монетизация рекламой или покупками также входит в требования. Игра доступна гостю, вход инициирует сам пользователь. Реклама/покупки через разрешённые механизмы площадки; не ставить собственную рекламную сеть.
Для архива, размещаемого Яндексом, официальный loader — `/sdk.js`; для внешнего хостинга документация указывает `https://sdk.games.s3.yandex.net/sdk.js`. Не скачивать sdk.js в репозиторий. После загрузки дождаться `YaGames.init()`.
Перед первым интерактивным экраном проверить `ysdk.features.LoadingAPI.ready()` и актуальные gameplay/pause события. Звук и активное взаимодействие при паузе/потере фокуса должны вести себя по требованиям.

## Реклама и IAP
Fullscreen — в естественной паузе, не поверх активного drag. Rewarded награждает по `onRewarded`, не по `onClose`. Поддержать отсутствие объявления.
IAP: каталог платформы, корректная цена/валюта, durable delivery и повторная обработка незавершённых покупок; consume по правилам продукта. signed=true выбирать только при действительной серверной проверке, не для галочки. При покупках проверить дополнительные требования к облачному прогрессу.

## Сохранения/лидерборд
У игрока есть SDK-хранилище; согласовать конфликт локального и облачного состояния и лимиты. Не очищать гостевой прогресс при предложении входа.
**Актуальный namespace — `ysdk.leaderboards`**. Старый `ysdk.getLeaderboards()` помечен устаревшим. Сначала создать таблицу в консоли и проверить техническое имя. Для `setScore` нужен авторизованный пользователь; проверять `isAvailableMethod`. Использовать реальные записи, отсутствие записи — не ошибка всей игры. Учитывать квоты из текущей страницы.

## В профиль проекта
Game ID, hosted/external mode, языки/устройства, native/bridge и версия, monetization status, product/board IDs, события ready/start/stop, схема save. Секреты не хранить.
Лицензионная схема описывает физлиц, самозанятых, ИП/юрлиц, но переход и статус договора проверяются в конкретном кабинете. Не применять условия ЕЛС к аккаунту, который на неё не перешёл.

## Уточнить продукт
Публикация через Playgama и использование открытого Bridge в другом маршруте — разные решения. SDK поддерживает несколько хостов, но не получает за разработчика договоры/права размещения.
Документация сейчас **v2**. Существующую v1 нельзя обновлять без отдельного плана. JS-core и engine-plugin могут инициализироваться разными способами; не вызывать init повторно поверх автоматической инициализации плагина.

## Обязательное ядро интеграции
Для JS документируется `bridge.initialize()`. API overview требует язык платформы, Bridge Storage, корректную паузу/звук и `platform.sendMessage('game_ready')` при готовности игры. Сигнатуры и события сверить с версией используемого плагина.
По текущим требованиям: Bridge обязателен при подаче; index.html в корне ZIP, латинские имена файлов; общий объём файлов до 300 MB. Это верхний предел, не целевой бюджет MVP.
Нет обязательного внешнего логина, встроенной сторонней аналитики вроде GA4 и собственного domain-lock. Корректный resize/orientation и заявленные устройства. Не копировать устаревшие строки минимальных ОС в обещание поддержки современной Unity: проверять реальный runtime и согласовывать устройства.

## Возможности
Rewarded/payments/leaderboards зависят от хоста и режима. `bridge.leaderboards.type` может быть not_available/in_game/native/native_popup. При not_available скрыть UI. Таблица поддержки Bridge отдельно от прямого native API хоста.
SaaS leaderboard поверх backend — отдельное подключение, не автоматически бесплатная native-функция. Проверить цену/доступ/аккаунты до согласования. Для покупок сначала capability и допуск конкретной игры; не делать обязательный магазин.

## Дистрибуция и деньги
FAQ описывает разные условия для разных каналов и индивидуальное решение выплат физлицам по юрисдикции. Условия и пороги фиксировать по текущему договору, а не копировать рекламный процент без базы net revenue.
Публичное заявление о банковских выплатах не заменяет письменное подтверждение конкретному российскому контрагенту/банку. Согласовать исключения каналов, уже занятых прямой публикацией или другим дистрибьютором.

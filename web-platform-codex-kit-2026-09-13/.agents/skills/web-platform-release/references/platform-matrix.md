# Матрица площадок — проверено 2026-09-13

Это технические исходные ориентиры, не гарантия доступа кабинету или выплат. Детали/источники — в отдельных документах.

| Направление | Реклама | IAP | Общий лидерборд | Существенное ограничение |
|---|---|---|---|---|
| Яндекс Игры | SDK | SDK + активная монетизация | Native, настройка в консоли; отправка авторизованным | SDK и monetization нужны для публикации; гостевой режим |
| VK | Зависит от точного runtime/договора | Зависит от runtime/доступа | Не считать встроенным по умолчанию | Сначала Mini Apps vs legacy Games; dev.vk.com требует ручной сверки |
| ОК | Маршрут-зависимо; legacy FAPI документирован | Маршрут-зависимо | Не считать доступным автоматически | Для новых приложений FAQ направляет в VK Mini Apps |
| CrazyGames | Basic: выключена; Full: SDK | Только допущенным играм | Native invite-only | SDK-провайдер может не поддерживать даже доступную native-функцию |
| Poki | Только Poki SDK | Нет в текущей модели | Не предполагать API; accounts/AUDS ≠ leaderboard | Отбор, mobile/tablet, разные сделки в т.ч. web-exclusive |
| GameDistribution | GD SDK | Store API документирован, доступ/условия не подтверждены | Базовая поддержка не подтверждена | Сеть партнёров; согласовать каналы и контракт |
| Playgama | Bridge | Поддержка зависит от площадки/допуска | Native/SaaS — отдельные режимы | Bridge v2; SDK-support ≠ право/доступ публикации |

Глобальный leaderboard — опция, не условие любого MVP. Для рекламы без backend предложить личный рекорд. Состав платформ можно расширить, но не выдумывать правила: новая площадка сначала получает проверенный документ и профиль.
